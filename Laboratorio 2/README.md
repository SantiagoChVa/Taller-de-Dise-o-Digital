Laboratorio 2 – Microcontrolador RISC-V
Descripción

Implementación de un sistema empotrado en FPGA (Nexys4) basado en un microcontrolador RISC-V (RV32I). El sistema integra memoria ROM, memoria RAM, bus driver y periféricos (UART, LEDs y switches/botones).

Funcionamiento

El sistema recibe una operación aritmética por UART (suma o resta), la procesa y envía el resultado de vuelta.
